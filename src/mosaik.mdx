# Mosaik

Mosaik is the UI foundation for Mocka. Version 0.1 exposes a public React 18/19 ESM package.
Import `@mocka/mosaik/styles.css` once at the application root. The published package does not
load web fonts or ship a CSS reset.

Storybook imports local Fontsource packages for **Parkinsans** and **DM Sans** in its preview only.
Consumer applications remain responsible for loading or self-hosting fonts, keeping the published
CSS contract network-free.

## Foundations

- Corners: a 16px rounded pair and 4px sharp pair (`--mk-c1` / `--mk-c2`), reversible with `data-mk-corner="trbl"`.
- Colors: primary `#3746E6`, secondary `#FF6E64`, semantic colors, cool neutrals, and light/dark palettes.
- Type: Parkinsans for display, buttons, and labels; DM Sans for interface text.
- Motion: `--mk-ease-standard`, `--mk-ease-out`, and `--mk-ease-overshoot`.

## Component families

- Forms: Button, TextField, Textarea, Select, Checkbox, Radio, and Switch.
- Display: Badge, Tag, Card, Triangle, Avatar, Progress, Skeleton, and EmptyState.
- Navigation: Tabs, SegmentedControl, ActionMenu, Breadcrumb, Pagination, and LinkButton.
- Overlays: Modal, FloatingLayer, Drawer, Toast, and CommandPalette.
- Data and content: Table, CodeBlock, InlineCode, Kbd, Accordion, Dropzone, and Wizard.
- Layout and typography: Container, Section, Stack, Cluster, Grid, Surface, Divider, Heading, Text, and Prose.

See **Mosaik / All components** for the full specimen sheet and dedicated component stories for
states, semantics, corner axes, themes, and responsive behavior.

## CSS entrypoints

- `@mocka/mosaik/styles.css` — tokens and component styles.
- `@mocka/mosaik/tokens.css` — tokens only.
- `@mocka/mosaik/components.css` — component styles only.

The `.dark` class activates the dark palette. Add `data-mk-corner="trbl"` to reverse the corner
axis for a subtree.
